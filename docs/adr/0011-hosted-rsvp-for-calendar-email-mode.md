# Use hosted RSVP tracking for calendar email mode

When calendar email mode is added, we will track invite responses through signed hosted RSVP links for accept, decline, tentative, and add-to-calendar actions. Native email client calendar responses are useful but cannot be trusted as the only analytics source across Gmail, Outlook, Apple Calendar, and other clients; our own RSVP flow gives the platform a consistent response record while still allowing recipients to add the event to their calendar.
